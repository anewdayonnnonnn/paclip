（1）★ 口径坑：训练口径与评估口径必须成对，否则结论全错

  现象：用 `python -m text_side_anomaly.train` 重训脑基线，评出来 Dice 0.4630 /
  0.4713 / 0.4712（三种子，抱得很紧），而记录里的基线是 0.5535 —— 差 0.08，
  远超种子噪声，看起来像"重训复现不了旧结果"。

  实际原因：`config.py` 在基线 ckpt 训完之后（9-23 08:55）加了一行

      ms_layers: List[int] = field(default_factory=lambda: [5, 8, 11])

  而 `train.py` 建 `Config(...)` 时**没有显式设 ms_layers** —— 于是"重训基线"实际上
  训的是**多尺度**模型，我却拿单层口径去评它。

  判别式（同 ckpt 按两种口径评，训练与评估一致的那边明显更好）：

    ckpt                                  单层口径 Dice   多尺度口径 Dice
    原 ckpt/（单层训的，记录 0.5535）          **0.5535**        0.4245
    原 ckpt_ms/（多尺度训的，记录 0.6039）      0.4731         **0.6039**
    我重训的那三组                            0.4630         **0.5973**

  换成匹配口径后，重训的多尺度是 0.5973，与记录的 0.6039 只差种子噪声 ——
  **根本没有 −0.08 这回事**。

  已修：`train.py` 新增 `--ms-layers`（none = 单层基线；逗号分隔给多尺度），
  不给则用 Config 默认值。**要基线必须显式传 `--ms-layers none`**，
  因为 Config 的默认值已经不是单层了。教训写成 README 的「两个坑」之一。

（2）脑：基线与多尺度，各 4 次独立训练的均值（口径与训练一致）

    配置              imgAUROC    Dice     IoU   pxAUROC   脑外红斑(异常/正常)  红灯真病灶率

    多尺度             0.9716   0.6013  0.4299   0.9565      15.7% / 53.3%       59.1%

  逐次（原 ckpt + 3 种子）：
    基线   0.5535 / 0.5559 / 0.5605 / 0.5594   极差 0.0070
    多尺度 0.6039 / 0.5973 / 0.6012 / 0.6026   极差 0.0066

  两条结论：
    ① 原 ckpt 的 0.5535 落在重训种子的区间内，**且在四次里最低** —— 它不特殊，
       只是随机初始化的一次抽样。基线复现了。
    ② **种子极差只有 0.007**，而多尺度的增益是 +0.044，是极差的 6 倍 ——
       这个增益是真的。所以脑这边单种子对比可信（与改动 17 胸腺 K=5 种子跨度 0.11
       形成对照：那里是样本量太小，这里是训练充分）。

    多尺度+门控 0.6125、ROI训练 0.2351、ROI训练+门控 0.7080。

    --seed       固定 random / numpy / torch / cuda 随机性。原本**没有种子**，
                 每次重训都不一样，对比实验无从谈起。凡要对比必须显式给定。
    --ms-layers  见 (1)。默认 None = 用 Config 默认值（注意那已不是单层）。

  `[train] ms_layers=[...] (单层/基线 | 多尺度)`，让口径在日志里可见。
